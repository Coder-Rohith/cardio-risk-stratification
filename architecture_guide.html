How Frontend & Backend Communicate
Architectural design of Streamlit's reactive loop and IPC latency

Unlike traditional decoupled web apps (e.g. React single-page apps communicating with REST APIs via HTTP REST/JSON fetch over the network), CardioRisk AI leverages a single-process unified architecture using Streamlit:

  • WebSocket Event Transport: When a user drags a slider or changes a dropdown in the browser UI, a lightweight binary event payload is sent across a persistent WebSocket connection to the Python Tornado server.
  • Zero Network Latency Preprocessing: Because the UI code (app/streamlit_app.py) and ML engine (src/models.py) execute inside the exact same Python process memory space, feature vectors are passed directly in RAM as NumPy/pandas objects (zero HTTP serializing or network overhead).
  • Cached Model Artifacts (@st.cache_resource): Model binary weights, scalers, and SHAP explainers are loaded into process memory once at startup. Subsequent patient predictions reuse pre-compiled memory references.
# In app/streamlit_app.py - Models loaded once into process RAM @st.cache_resource def load_models(): artifacts = {} artifacts["preprocessor"] = ClinicalDataPreprocessor().load("models/preprocessor.joblib") artifacts["ensemble"] = joblib.load("models/ensemble_model.joblib") return artifacts # Execution loop: Runs in ~67ms on local CPU t0 = time.perf_counter() X_patient = artifacts["preprocessor"].transform(patient_data) ensemble_prob = artifacts["ensemble"].predict_proba(X_patient)[0, 1] latency_ms = (time.perf_counter() - t0) * 1000

SHAP Explainability Core
TreeExplainer for local and global clinician feature attributions

SHAP (SHapley Additive exPlanations) grounds model transparency in cooperative game theory. The model prediction is expressed as:

# Additive Feature Attribution Formula f(x) = E[f(X)] + ∑ φ_i(x) Where: E[f(X)] = Baseline expected risk score (~11.5%) φ_i(x) = Patient-specific contribution of feature i φ_i > 0 = Increases risk (e.g. Smoking, SBP 160mmHg) φ_i < 0 = Protective factor (e.g. HDL 65mg/dL, Active)
